## Context

Toolkit 是一个基于 Tauri 2.0 + Vue 3 的桌面工具应用，目前已实现 JSON、YAML、XML、Base64、二维码、Hash、文本编解码、时间戳、文档格式转换等工具。现在需要添加计算器功能，支持多种计算场景。

## Goals / Non-Goals

**Goals:**
- 支持基础计算器（加减乘除、百分比、记忆功能等）
- 支持科学计算器（三角函数、对数、幂运算等）
- 支持程序员计算器（进制转换、位运算、字节转换）
- 支持单位转换（长度、重量、温度、面积、体积）
- 支持日期计算（日期加减天数）
- 支持金融计算（贷款月供、利息计算）
- 响应式界面设计，支持键盘快捷键

**Non-Goals:**
- 不支持图形绘制
- 不支持方程求解
- 不支持统计分析

## Decisions

### 1. 计算器架构设计

**选择：组件化架构，每个计算器模式一个组件**

理由：
- 代码清晰，易于维护
- 可以独立开发和测试每个计算器
- 方便后续扩展新的计算器类型

替代方案：
- 单一组件：代码会过于复杂
- 函数式：不适合 Vue 的组件化开发

### 2. 数学运算实现

**选择：纯 JavaScript/TypeScript 实现**

理由：
- 无需额外依赖
- 精度足够日常使用
- 性能好

替代方案：
- math.js：功能强大但体积大
- decimal.js：高精度但日常使用不需要

### 3. 单位转换实现

**选择：预定义转换表**

理由：
- 简单直接
- 性能好
- 易于维护

替代方案：
- 动态计算：复杂且容易出错

### 4. 界面布局

**选择：标签切换 + 按钮网格**

理由：
- 符合用户习惯
- 界面清晰
- 操作方便

替代方案：
- 侧边栏：占用空间大
- 下拉菜单：操作不便

## Risks / Trade-offs

1. **浮点数精度**
   - 风险：JavaScript 浮点数计算可能有精度问题
   - 缓解：使用 toFixed() 控制显示精度，关键计算使用整数运算

2. **单位转换覆盖度**
   - 风险：可能遗漏某些单位
   - 缓解：提供常用单位，后续可扩展

3. **金融计算准确性**
   - 风险：贷款计算可能与银行计算有差异
   - 缓解：明确标注计算方式，提示仅供参考
