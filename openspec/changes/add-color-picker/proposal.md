## Why

开发者经常需要从屏幕中提取颜色值用于 CSS、设计或调试。目前需要切换到外部工具（如 macOS 数字测色计、第三方取色器），流程割裂。在 Toolkit 中集成取色器，可以直接在工具内完成取色 → 复制颜色值的完整流程。

## What Changes

新增"取色器"工具，支持从屏幕任意位置提取颜色值。

**核心功能**：
- 点击"取色"按钮，激活系统级吸管工具
- 点击屏幕任意位置获取该像素颜色
- 显示颜色预览色块
- 多格式输出：HEX、RGB、HSL
- 一键复制颜色值

**交互流程**：
1. 用户进入取色器工具
2. 点击"取色"按钮
3. 工具窗口最小化，系统吸管光标出现
4. 用户点击屏幕任意位置
5. 工具窗口恢复，显示颜色值
6. 用户可复制任意格式的颜色值

**技术方案（优先级）**：
1. **首选：EyeDropper API** — 浏览器原生 API，零依赖，~10 行代码
2. **备选：Rust 原生截图** — 如果 EyeDropper 在 macOS WKWebView 中不可用
